# Maze-Solver
This project uses python3 and Tkinter to randomly generate and solve a maze.

## Goals
This project was an exercise in making a python program using a GUI, and practicing recursion using a depth first search to find the solution to the maze after it is generated each time.

## Clone the repo

```
git clone https://github.com/gdragonedev/Maze-Solver@latest
cd Maze-Solver
```

## Prerequisites
### 1. Python 3 (v3.10+)
### 2. Tkinter
Try running the following command to see if Tkinter is installed:
```
python3 -m tkinter
```
If a window pops up with some buttons inside, you're all set.Otherwise, you may see the following if you are missing the dependency:
```
ModuleNotFoundError: No module name '_tkinter'
```
Tkinter depends on the Tcl/Tk library. Installing the 'tk-dev' or 'python-tk' packages are a good way to install tkinter.

## Usage
After prerequisites are installed, from the root of the project run:

```
python3 src/main.py
```
